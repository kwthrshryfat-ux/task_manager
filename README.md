# Task Manager

یک برنامهٔ ساده برای مدیریت وظایف با پایتون.

## قابلیت‌ها
- افزودن، ویرایش، حذف و نمایش وظایف
- علامت‌گذاری وظیفهٔ انجام‌شده
- ذخیرهٔ خودکار در فایل JSON

## اجرا
    python main.py

## ساختار
- `models.py`: کلاس‌های Task و TaskManager
- `storage.py`: خواندن و نوشتن JSON
- `main.py`: منوی برنامه
